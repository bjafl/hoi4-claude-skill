## Summary

Hearts of Iron IV receives free patches that fix bugs and implement balance tweaks, often released alongside major DLC. Hotfixes are small updates addressing urgent bugs. Newer DLC cannot be activated on older patch versions; mods have varying compatibility with patches. This timeline covers major version releases from 1.0 (June 2016) through 1.19.2 (June 2026).

## Patch distribution model

**Patches** fix bugs and/or balance tweaks; often released with major DLC, with some DLC features made free to all players.

**Hotfixes** are smaller updates addressing specific bugs or exploits, sometimes released immediately after a major patch.

Note: New DLC requires matching the DLC's patch version. Mods have varying compatibility levels per patch.

## Checksum and validation

Each patch version has a checksum (four characters visible in launcher bottom-right and in-game main menu). The vanilla checksum is required for achievements and standard multiplayer play. Mods and debug options change the checksum; verify it matches the intended version before playing multiplayer or attempting achievements.

To roll back to an earlier version: open Steam Properties → Betas → Beta Participation dropdown, select the desired version. Note: Pre-GDPR versions (before October 1, 2018) require different rollback steps.

## Playing earlier versions

To continue playing a game started on an earlier patch version:

1. Open Steam Library
2. Right-click Hearts of Iron IV → Properties
3. Click Betas tab, select desired version from the dropdown (default: None = current version)
4. Steam installs the selected version

Versions shown here are earlier *released* versions, not beta versions. Choosing an older version allows compatibility with existing saves if the current version breaks them.
