

===== PAGE: Achievements =====
See also: Career profile
Hearts of Iron IV has 293 (191 on Xbox) different achievements, all using the Steam or Xbox achievements mechanics. Achievements have no in-game effects; the achievement just pops up in-game, and is then added to the player's Steam or Xbox profile depending on the version of the game. It is possible to see the achievements sorted by the percentage of users that managed to complete each achievement by going to the game's global achievements at Steam or by using the built-in Sort options in the Xbox achievements list.

Achievements can only be gained in single-player Ironman games, with the 1936 start, on regular, veteran or elite difficulty. (30 Minutes of Hel and Don’t Die for Your Country can only be completed in the 1939 start date). They can be earned while playing older versions of the game as long as said achievements were present in that version. They can also be earned with Historical AI Focuses set to off. (Note: There is no "end date", the game can be continued indefinitely)

It is not possible to gain achievements if the checksum has been changed - either by tampering with game files, or by running the game using mods that affect gameplay mechanics (graphical mods do not affect checksum), or a corrupted installation.

Please note that the Xbox version of the game is no longer kept up to parity with Steam since March 1st, 2024 and as such, the Xbox version does not have achievements for Trial of Allegiance and will not receive any future expansions.

## Setting AI behavior for achievement runs

Although changing custom game rules usually locks a game out of being eligible for achievements, using the tab "AI Behavior" along with unchecking Historical AI Focuses can allow you to haphazardly preset what nations you want to be historical or not.

Uncheck Historical AI Focuses. Go into Custom Game Rules and into the AI behavior tab. Changing a country's path from Default to a defined path makes the game non-iron man, but not if you specifically select the historical route, e.g. changing [Flag of Germany] Germany's path from Default to Fascist. Now change every country you want to stay historical from Default to their ironman-compatible set path, with every country you want to possibly go a-historical still set on Default. This way, the game will only have countries with Default set as their path possibly go non-historical, though it is not guaranteed.

This allows you to, for example:

- Only set [Flag of Japan] Japan to Default, which will possibly make them go non-historical and not attack the [Flag of United States] United States, who will, in turn, not join the Allies. This is especially useful for world conquest runs as it allows you to beat the Allies after 1941.
- Only set [Flag of United Kingdom] United Kingdom to Default, which possibly makes the UK disband the Allies. Again, very useful for runs in which you have to beat the Allies.

Note that other countries might still go non-historical although you set them to their historical path, likely due to focuses from a-historical nations influencing these.

## List of achievements

- The descriptions on this page are taken from the in-game achievement list; the descriptions on Steam (or other platforms) may be different.
- The Notes column includes clarifying information regarding the achievement and helpful tips/guides. Please keep this section concise and as short as possible.
- The [Hearts of Iron IV] column denotes achievements which can't be completed without the use of DLC mechanics (currently 92 out of 249). Multiple expansion icons mean either can be used.
- The Ver column indicates in which version a certain achievement was added. Achievements cannot be earned prior to the version they were added in.
- The DI column indicates the achievement's difficulty level. It can be changed according to player consensus.

  The difficulty levels are:VE = Very Easy,E = Easy,M = Medium,H = Hard,VH = Very Hard,I = Insane,UC = Uncategorized.
